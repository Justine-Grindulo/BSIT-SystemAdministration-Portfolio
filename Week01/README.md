## Challenges Encountered

1. **Configuring Git for the first time** – Before I could commit, Git required my username and email. I set them with:
   ```bash
   git config --global user.name "Justine-Grindulo"
   git config --global user.email "your-email@example.com"
   ```
2. **Authenticating with GitHub** – GitHub no longer accepts account passwords when pushing from the terminal. I had to sign in through the browser prompt (Git Credential Manager) / use a Personal Access Token before my push went through.
3. **Connecting the local folder to the remote repository** – I had to learn the correct order of `git init`, `git remote add origin`, `git add`, `git commit`, and `git push` to upload my portfolio without errors.
